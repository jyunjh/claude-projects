# LINE と共有品目リストの設定手順（初回だけ・約15分）

アカウント作成とトークンの発行は本人の操作が必要です。トークン・合言葉は**チャットやリポジトリに貼らない**でください（Googleのスクリプトプロパティにだけ入れます）。

## 1. LINE公式アカウント（Messaging API）を作る
1. <https://developers.line.biz/console/> に LINE アカウントでログイン。
2. 「プロバイダー作成」（名前は何でもよい。例: `うちの家計`）。
3. そのプロバイダーで「Messaging API チャネルを作成」→ LINE公式アカウントの作成画面に進むので、アカウント名を `特売アラート` などにして作成。
   - 作成後、LINE Official Account Manager の「設定 → Messaging API」で「Messaging API を利用する」を有効化し、上のプロバイダーを選ぶ。
4. LINE Official Account Manager の「応答設定」で
   - **応答メッセージ: オフ**（自動の定型返信を止める）
   - **Webhook: オン**
   - あいさつメッセージ: お好みで（オフ推奨。登録時はボットが案内を返す）
   - 「グループ・複数人トークへの参加を許可する」: 夫婦のグループで使うならオン
5. LINE Developers コンソール → チャネル →「Messaging API設定」タブの一番下で**チャネルアクセストークン（長期）を発行**し、控えておく。

> 料金: 無料の「コミュニケーションプラン」で月200通まで。朝の配信は 夫婦2人×30日＝約60通。「今日」「一覧」などへの返信は数に入りません。

## 2. Google シートと Apps Script
1. Google ドライブで新しいスプレッドシートを作る（名前: `特売アラート`）。
2. メニュー「拡張機能 → Apps Script」。
3. 最初からある `コード.gs` の中身を全部消して、リポジトリの `sale-alert/gas/Code.gs` を貼る。
4. 左の「＋ → スクリプト」で `match` というファイルを作り、`sale-alert/gas/match.gs` を貼る。
5. 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」に追加:

   | プロパティ | 値 |
   |---|---|
   | `LINE_TOKEN` | 手順1-5のチャネルアクセストークン |
   | `PASSCODE` | 自分で決める合言葉（英数字20文字以上を推奨） |
   | `DATA_BASE_URL` | `https://jyunjh.github.io/claude-projects/sale-alert/` |
   | `NOTIFY_WHEN_EMPTY` | （任意）`false` なら一致なしの日は送らない |

6. エディタ上部の関数選択で `setup` を選んで「実行」→ 権限の確認が出るので許可（自分のアカウントで作ったスクリプトなので「詳細 → 安全ではないページに移動」で進めてよい）。
   シートに `items` `recipients` `inbox` `log` タブができ、毎朝7時台のトリガーが登録されます。
7. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   → デプロイして出る **ウェブアプリの URL**（`…/exec`）を控える。
   > コードを貼り替えたときは「デプロイを管理 → 編集 → バージョン: 新バージョン」で同じURLのまま更新する。

## 3. LINE と Apps Script をつなぐ
1. LINE Developers →「Messaging API設定」→ Webhook URL に手順2-7の URL を入れて「更新」、「Webhookの利用」をオン。
   - 「検証」ボタンはエラー表示になることがありますが（Apps Script がリダイレクトを返すため）、実際の受信は動きます。次の手順で確認してください。
2. 同じ画面の QR コードで、自分と奥さんのそれぞれが友だち追加する。
   - または夫婦のグループにこのアカウントを招待する（グループに配信されます）。
3. トークで `ヘルプ` と送り、使い方が返ってくれば接続OK。`追加 卵` と送るとシートの `items` に行が増えます。
4. Apps Script エディタで `testPush` を実行すると、朝の配信をその場で試せます。

## 4. アプリ（PWA）をつなぐ
1. スマホで `https://jyunjh.github.io/claude-projects/sale-alert/` を開く。
2. 「設定」タブで Apps Script の URL と合言葉、自分の名前を入れて「保存して接続」。
3. 「共有リンクをコピー」→ 奥さんに LINE で送る（開くだけで同じ設定になります。合言葉を含むので家族以外に送らない）。
4. それぞれホーム画面に追加。

## セキュリティ上の注意
- Apps Script は LINE の署名ヘッダーを読めない仕組みのため、**ウェブアプリの URL を知っている人は LINE を装って品目を追加できます**。URL は家族以外に共有しないでください（リポジトリにも入れていません）。
- 合言葉はアプリ（品目の読み書き）と取り込みスクリプト（受付箱）で使います。漏れたら `PASSCODE` を変えて、共有リンクを送り直してください。
- リポジトリは公開です。公開されるのはチラシの特売情報と店舗一覧だけで、品目リスト・宛先・受付箱の写真は Google 側に残ります。

# 米国マクロ景況モニター / macro-monitor

米国の景気の位置を、少数の指標で毎日確かめるためのダッシュボード。
CFA Level 3 PSM Macro の講義の読み方に沿って、指標ごとに「一言」と「解説」を付けている。

- 公開ページ: https://jyunjh.github.io/claude-projects/macro-monitor/
- 使うのは**無料・APIキー不要の公開データだけ**。取得・計算・判定はすべて Python で、LLM は使わない。
- 平日の朝 08:37（日本時間）に GitHub Actions が全データを取り直して配信する。

## 画面の構成

| タブ | 中身 |
|---|---|
| 総合 | 景気局面（回復／ピークアウト／収縮）、景気循環のサインの判定、ターニングポイント6項目、全指標の一覧 |
| 景気循環のサイン | 逆イールド（10年−3ヶ月）、CPI総合の前年比、労働の質（3つのうち2つ以上） |
| ヘッドライン | NAHB住宅市場指数、地区連銀PMI（ISM換算）、新規受注 |
| 金利の先取り | 18ヶ月時計（政策金利のサイクル）、S&P500 実績PER |
| 世界金利 | グローバル中銀 政策ディフュージョン指数 |
| ドル | 貿易加重ドル指数（TWD） |
| 出典・ログ | 出典と取得日時、取得エラー、過去の景気後退との突き合わせ結果 |

判定のルール:

- **景気循環のサイン**: 逆イールド・CPI・労働の質のうち**2つ以上が同時に点灯**したら景気後退寄りと見る。単独では判断しない。
- **ターニングポイント**: 利上げ開始から18ヶ月／逆イールド／PERの縮小／新規受注のピークアウト／NAHBの悪化／労働市場の構造的変化 の6項目のうち、いくつ該当しているかを数える。
- **景気局面**: 講義の3区分（リスクオン＝PMI上昇、リスクオフ＝50以上で低下、リスク回避＝50割れでなお低下）を、地区連銀PMIの水準と向きで機械的に当てはめる。

### 自分で作っている系列の定義

**地区連銀PMI（ISM換算）— ISM製造業PMIの代わり**

ISMのPMIは有料配信で、無料では取り続けられない。代わりに、同じ形式の調査を公開している
フィラデルフィア連銀（1968年〜）とNY連銀（2001年〜）の製造業調査から、ISMと同じ計算式で作る。

- 換算式: 地区連銀の各項目は D＝「増えた%」−「減った%」。ISMは「増えた%」＋「変わらない%」×½。
  「変わらない%」＝100−増えた%−減った% なので、**ISM換算＝50＋D÷2**（数式上ぴったり一致し、50の意味も同じ）。
- 項目: ISMのPMIと同じ5項目を等しい重みで平均 — 新規受注・出荷（ISMの生産に相当）・雇用・入荷遅延・在庫。
- 合成: 2地区の単純平均。2001年6月以前はフィラデルフィアのみ。2地区がそろうまでその月の値は出さない。
- ISM公表値との照合（2020年5月〜2025年8月の64ヶ月）: 相関0.90、平均の差+0.5、50割れの判定の一致は54/64。
  `python3 tools/backtest.py --ism` で再現できる（ISMの値は DBnomics の転載。2025年12月で更新が止まっている）。
- 限界: 東部の2地区だけで、全米を対象にするISMよりサンプルが小さい。

**グローバル中銀 政策ディフュージョン指数**

各月について「6ヶ月前より政策金利を上げた中銀の割合(%) − 下げた中銀の割合(%)」。
BISの月末値を使い、その月と6ヶ月前の両方に値がある中銀だけを数える。
講義の図と同じ出どころではない自前の指数なので、ランプは付けず文脈として表示する。

## しきい値の根拠（A / B）

画面のタグと同じ区別をコードでも守る（`tools/indicators.py`）。

- **A（講義・史実）**: 逆イールド 0pt、CPI 5%、PMI 50、利上げ開始から18ヶ月
- **B（当ツール較正）**: 過去の景気後退（NBERの山8回）で実測してから置いた目安。
  根拠の数字は更新のたびに `tools/backtest.py` が数え直して画面に埋める。

2026年11月時点の実測（条件が3ヶ月続いた発生を、山の24ヶ月前〜3ヶ月後なら的中、それ以外を誤報と数える）:

| シグナル | 的中 | 誤報 | 扱い |
|---|---|---|---|
| 労働の質（3つのうち2つ以上） | 8/8 | 2回 | 3ヶ月続いたら警告。ただし先行は多くの回で1〜2ヶ月（ほぼ一致指標） |
| └ フルタイム÷パート比率（6ヶ月平均の前年比がマイナス） | 7/8 | 11回 | 単独では使わない |
| └ 政府雇用比率（12ヶ月前より上昇） | 8/8 | 3回 | 単独では使わない |
| └ 継続受給者数（2年安値比+10%以上） | 8/8 | 3回 | 単独では使わない |
| 地区連銀PMI 50割れ | 6/8 | 13回 | 「製造業の縮小」。景気後退の予告としては使わない |
| 新規受注のピークアウト（12ヶ月高値から7pt低下） | 7/8 | 12回 | 注意どまり。3pt・5ptは誤報22回 |
| NAHB 1年で10pt以上の悪化 | 3/4 | 5回 | 注意どまり |
| NAHB 50割れ（不採用） | 2/4 | 5回 | 2024年5月から30ヶ月連続で点いたままになるため使わない |
| PER 前年比マイナス | 7/8 | 12回 | 注意どまり |

## 使い方

```bash
./update.sh            # 手元で更新（初回だけ .venv を作って xlrd を入れる）
./update.sh --force    # キャッシュを無視して取り直す
./verify.sh            # snapshot の自己検証＋JSの構文チェック（ネットワーク不要）
python3 -m http.server 9030 --directory .   # http://localhost:9030 で画面を見る
.venv/bin/python tools/backtest.py          # 全シグナルを過去の景気後退と突き合わせる
```

`index.html` はブラウザで直接開いても読める（`data/snapshot.js` を `<script>` で読む）。

### 公開ページの更新

- **自動**: `.github/workflows/pages.yml` が平日 08:37 JST に実行する。Pages はサイト全体を置き換えるので、
  このワークフローは他のツール（児童館カレンダーなど）も必ず一緒に組み立てて配信する。
- **「🔄 最新を読み込む」**: 配信済みのデータを読み直すだけ（設定不要）。
- **「⚡ 今すぐ取得し直す」**: ブラウザから上のワークフローを起動する。初回だけ、GitHubで
  fine-grained personal access token（対象: このリポジトリのみ／権限: Actions の Read and write のみ）を作り、
  画面の「⚙ 設定」に貼る。トークンはその端末のブラウザにだけ保存され、リポジトリには入らない。
  そのため画面は外部のスクリプトを一切読み込まない（グラフも自作の `chart.js`）。
- `data/snapshot.json` はリポジトリに控えを1つ置いているが、毎日のコミットはしない
  （毎回すべての期間を取り直すので履歴を積む必要がない）。控えは、取得が全滅したときの最後の保険。

## 更新の作り

- 1つのソースが落ちても全体は落とさない。落ちた指標は、公開中の前回データを「前回の値を表示中」として出す。
  前回データも無ければ「取得できていない」と出す。古い値を新しい値のふりをさせない。
- 2025年10月は政府閉鎖でCPIと家計調査が公表されていない。前後の月から直線で補間し、補間した月を画面に明記する。
- multpl のPERは、決算が出そろうまでの直近数ヶ月が推定値。グラフでは点線にする。
- 過去のランプや線は、最新の改定後データで計算し直したもの（当時の速報値ではない）。

## ファイル構成

```
macro-monitor/
├── index.html / app.js / styles.css   画面（数字は作らない。snapshot をそのまま映す）
├── chart.js                           自作の折れ線グラフ（外部ライブラリなし）
├── knowledge.js                       各指標の「一言」と「解説」（講義の要約と出典）
├── update.sh / verify.sh              手元で回すためのラッパー

│   ├── update.py                      取得 → 判定 → snapshot 書き出し
│   ├── indicators.py                  指標の組み立てと総合判定
│   ├── signals.py                     シグナルの定義（ランプとバックテストが同じ関数を使う）
│   ├── backtest.py                    過去の景気後退との突き合わせ、ISMとの照合
│   ├── seriesutil.py                  月次系列の小道具
│   ├── loader.py                      取得のまとめ役
│   ├── verify.py                      snapshot の自己検証
│   ├── extract_lectures.sh            講義の .docx を手元でテキスト化（公開しない）

├── data/snapshot.json, snapshot.js    生成物
├── cache/                             取得した生データ（git管理外）

```

## 注意書き

- 学習・観測のためのツールで、投資助言ではない。
- 解説は講義の要約で、講義の文章そのものは載せていない。
- しきい値Bは当ツールが過去データで置いた目安で、講義や公的機関が示した基準値ではない。
